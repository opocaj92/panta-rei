# Assets

Final artwork will eventually be placed here.

- `backgrounds/` — scene backgrounds and large compositions
- `characters/` — character artwork
- `animations/` — reusable animation sequences
- `effects/` — transitions and visual effects
- `fonts/` — game fonts
- `audio/` — sound effects and ambience
- `music/` — music

The first prototype deliberately draws placeholder graphics in Pygame.

Keep logical asset names stable when replacing artwork. Scene code should refer
to logical names, not individual image files.
